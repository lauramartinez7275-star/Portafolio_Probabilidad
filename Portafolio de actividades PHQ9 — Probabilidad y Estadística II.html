Conceptos

Qué es el muestreo

Población y muestra. La población es el conjunto completo que interesa (aquí, 682 estudiantes); la muestra es la parte que realmente se observa. Se muestrea para estimar sin medir a todos.

Aleatorio simple: todos tienen la misma probabilidad de ser elegidos. Estratificado proporcional: se divide la población en grupos (estratos) y se toma de cada uno en proporción a su tamaño, para que ninguno quede sin representar.

Tamaño de muestra. Depende de la confianza, del margen de error y de la proporción esperada p (0.5 es el caso más conservador). Con población finita se corrige con la fórmula de Cochran.

Comprobar la aleatoriedad. Al repetir el muestreo, las muestras deben ser distintas entre sí y ninguna persona debe repetirse de forma sistemática.

def tamano_muestra(N, confianza=0.95, error=0.05, p=0.5):
    tabla_z = {0.90: 1.645, 0.95: 1.96, 0.99: 2.576}
    Z = tabla_z.get(confianza, 1.96)
    n0 = (Z**2 * p * (1 - p)) / (error**2)
    n = n0 / (1 + (n0 - 1) / N)
    return round(n)

n = tamano_muestra(N, confianza=0.95, error=0.05, p=0.5)

Conceptos

Qué es un intervalo de confianza

Un estimador puntual (x̄) da un solo número; el intervalo da un rango donde probablemente está el parámetro: \[ \text{estimador}\ \pm\ (\text{valor crítico})\cdot(\text{error estándar}) \]

Cómo se interpreta el 95%. Si el muestreo se repitiera muchas veces, el 95% de los intervalos construidos contendría el verdadero valor de la población. No es "95% de probabilidad de que μ esté en este intervalo": μ es fijo, lo que varía es la muestra.

Conceptos

Cómo se hace una prueba de hipótesis

  1. Plantear \(H_0\) (lo que se supone cierto) y \(H_a\).
  2. Fijar α antes de ver los datos.
  3. Calcular el estadístico de prueba.
  4. Comparar con el valor crítico o con el p-value.
  5. Decidir y concluir en el contexto del problema.

Errores. Tipo I: rechazar una \(H_0\) verdadera (probabilidad α). Tipo II: no rechazar una \(H_0\) falsa (probabilidad β). No rechazar \(H_0\) no prueba que sea cierta.

El p-value

Qué significa realmente el p-value

\[ p=P\big(\text{un resultado al menos tan extremo como el observado}\ \big|\ H_0\ \text{es verdadera}\big) \]

Sirve para medir qué tan sorprendentes son tus datos si \(H_0\) fuera cierta. Ejemplo: en la t pareada con 25 datos salió p = 0.42; si no hubiera diferencia entre presión académica y financiera, en 42 de cada 100 muestras así se vería una diferencia igual o mayor solo por azar.

Qué NO significa: no es la probabilidad de que \(H_0\) sea cierta; 1 − p no es la probabilidad de que \(H_a\) sea cierta; un p alto no demuestra \(H_0\); un p chico no dice que el efecto sea grande (con n enorme, diferencias mínimas dan p chico).

Relación con α. α es el umbral fijado antes (probabilidad de error tipo I); el p-value sale de los datos. Se rechaza \(H_0\) si \(p\le\alpha\).

df = pd.read_csv("https://raw.githubusercontent.com/Zaitr0/Phq-9-dataset/refs/heads/main/PHQ-9_Dataset_5th%20Edition.csv")

# Función que hace toda la prueba de hipótesis para la media de una variable.
# La hice como función (y no código suelto) para poder reusarla con cualquier
# columna numérica del dataset, no solo PHQ_Total, sin tener que reescribir nada.
def prueba_hipotesis_media(datos, mu0, alpha=0.05, cola="dos", nombre_variable="variable"):
    # datos: la columna numérica a analizar, ej. df["PHQ_Total"]
    # mu0: el valor contra el que comparamos la media (lo que dice H0)
    # alpha: nivel de significancia (0.05 = 95% de confianza)
    # cola: "izquierda", "derecha" o "dos", según cómo se plantee Ha

    n = len(datos)
    media_muestral = datos.mean()
    desv_muestral = datos.std(ddof=1)  # ddof=1 porque es desviación MUESTRAL, no poblacional

    # Checamos normalidad de forma rápida: si media y mediana están cerca,
    # es razonable asumir que los datos se comportan aprox. normal.
    # Con n grande esto pesa menos gracias al Teorema del Límite Central.
    mediana_muestral = datos.median()
    print("=== Normalidad ===")
    print(f"Media: {media_muestral:.2f} | Mediana: {mediana_muestral:.2f}")
    print("Si están cercanas, es razonable asumir distribución aprox. normal.\n")

    # H0 siempre es con "=", Ha cambia de símbolo según el tipo de cola.
    # Uso un diccionario como "traductor" en vez de un if/elif largo.
    print("=== Hipótesis ===")
    print(f"H0: μ = {mu0}")
    simbolo = {"dos": "≠", "izquierda": "<", "derecha": ">"}[cola]
    print(f"Ha: μ {simbolo} {mu0}\n")

    print("=== Nivel de significancia ===")
    print(f"α = {alpha}\n")

    # Regla: si la muestra es grande (n >= 30) usamos Z, si es chica usamos T
    # (con muestras chicas, T es más conservador porque hay más incertidumbre)
    usar_z = n >= 30
    print("=== Estadístico de prueba ===")
    print(f"n = {n} -> usamos {'Z' if usar_z else 'T'}")

    error_estandar = desv_muestral / np.sqrt(n)  # qué tanto varía la media muestral
    if not usar_z:
        gl = n - 1  # grados de libertad, solo aplica para T
        print(f"Grados de libertad: {gl}")

    # El estadístico mide, en "unidades de error estándar", qué tan lejos
    # está nuestra media muestral del valor que dice H0 (mu0)
    estadistico = (media_muestral - mu0) / error_estandar
    print(f"Valor de prueba: {estadistico:.4f}\n")

    # El valor crítico marca dónde empieza la "zona de rechazo" en la distribución.
    # Cambia según: Z o T, y según el tipo de cola.
    print("=== Valor crítico ===")
    dist = stats.norm if usar_z else stats.t
    args = () if usar_z else (n - 1,)  # T necesita los grados de libertad, Z no

    if cola == "dos":
        valor_critico = dist.ppf(1 - alpha / 2, *args)
        valores_criticos = (-valor_critico, valor_critico)
    elif cola == "derecha":
        valor_critico = dist.ppf(1 - alpha, *args)
        valores_criticos = (valor_critico,)
    else:  # izquierda
        valor_critico = dist.ppf(alpha, *args)
        valores_criticos = (valor_critico,)

    print(f"Valor(es) crítico(s): {[round(v, 4) for v in valores_criticos]}\n")

    # Decisión: comparamos el estadístico contra el valor crítico.
    # La comparación cambia de forma según el tipo de cola.
    print("=== Decisión ===")
    if cola == "dos":
        rechaza = abs(estadistico) > valor_critico
    elif cola == "derecha":
        rechaza = estadistico > valor_critico
    else:
        rechaza = estadistico < valor_critico

    if rechaza:
        print("Se RECHAZA H0 -> sí hay evidencia estadística a favor de Ha.")
    else:
        print("NO se rechaza H0 -> no hay evidencia suficiente para Ha.")

    print(f"\nConclusión: con un {(1-alpha)*100:.0f}% de confianza, "
          f"{'podemos' if rechaza else 'no podemos'} concluir que la media de "
          f"{nombre_variable} es {simbolo} {mu0}.\n")

    # El tipo de error depende de si rechazamos H0 o no:
    # Tipo I = rechazar algo que en realidad era cierto (falso positivo)
    # Tipo II = no rechazar algo que en realidad era falso (falso negativo)
    print("=== Tipo de error posible ===")
    if rechaza:
        print(f"Como rechazamos H0, el riesgo es Error Tipo I: "
              f"rechazar H0 cuando en realidad es verdadera (falso positivo). "
              f"Existe un {alpha*100:.0f}% de probabilidad de que esto pase.\n")
    else:
        print("Como NO rechazamos H0, el riesgo es Error Tipo II: "
              "no rechazar H0 cuando en realidad es falsa (falso negativo).\n")

    graficar_prueba(estadistico, valores_criticos, cola, usar_z, n)

    return {
        "n": n, "media": media_muestral, "estadistico": estadistico,
        "valores_criticos": valores_criticos, "rechaza_H0": rechaza
    }

# Dibuja la campana (normal o t, según corresponda) con la zona de rechazo
# sombreada en rojo, y marca con una línea azul dónde cae nuestro estadístico.
def graficar_prueba(estadistico, valores_criticos, cola, usar_z, n):
    x = np.linspace(-4, 4, 500)
    y = stats.norm.pdf(x) if usar_z else stats.t.pdf(x, n - 1)

    plt.figure(figsize=(7, 4))
    plt.plot(x, y, color="black")

    # Sombreamos la(s) zona(s) de rechazo según el tipo de cola
    if cola == "dos":
        izq, der = valores_criticos
        plt.fill_between(x, y, where=(x <= izq), color="red", alpha=0.5)
        plt.fill_between(x, y, where=(x >= der), color="red", alpha=0.5)
    elif cola == "derecha":
        plt.fill_between(x, y, where=(x >= valores_criticos[0]), color="red", alpha=0.5)
    else:
        plt.fill_between(x, y, where=(x <= valores_criticos[0]), color="red", alpha=0.5)

    plt.axvline(estadistico, color="blue", linestyle="--", label=f"Estadístico = {estadistico:.2f}")
    plt.title("Zona de rechazo vs estadístico de prueba")
    plt.legend()
    plt.show()

# Aplicamos la función al dataset real: usamos 10 como mu0 porque es el corte
# clínico de "depresión moderada" en la literatura del PHQ-9
resultado = prueba_hipotesis_media(
    datos=df["PHQ_Total"],
    mu0=10,
    alpha=0.05,
    cola="dos",
    nombre_variable="PHQ_Total"
)
